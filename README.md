# ⚡ BankLite - Mobile Banking Lite UI

A clean and modern **mobile banking interface** built with **HTML, Tailwind CSS, and Vanilla JavaScript**.

Designed to deliver a simple, intuitive, and mobile-first banking experience with a minimalist dashboard, transaction navigation, transfer interface, card management, and user profile.

> 💳 Mobile Banking • Minimalist UI • Transaction History • Transfer • Responsive Design

## 🛠 Tech Stack

- **HTML5** — Application structure
- **Tailwind CSS** — Utility-first styling via CDN
- **Vanilla JavaScript** — Client-side interactions
- **Custom CSS** — UI components and visual styling

No frontend framework required.

## ⚙️ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/arjalikastudio/Mobile-Banking-Lite-UI.git
```

### 2️⃣ Navigate to the project directory

```bash
cd banklite
```

### 3️⃣ Run the application

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.

## 🎨 Design Philosophy

BankLite focuses on simplicity, usability, and a mobile-first experience.

The interface uses a clean layout, consistent spacing, rounded components, and a fixed bottom navigation to make core banking sections easy to access.

The project is designed as a lightweight starting point for experimenting with mobile banking UI concepts and frontend interactions.
